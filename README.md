# BPMN Generator

Инструмент для автоматической генерации BPMN 2.0 диаграмм из текстового описания бизнес-процессов.
Работает через CLI-агент OpenCode со скиллами. Не требует GPU.

---

## Что нужно установить

### 1. Python 3.10+
- Скачать: https://www.python.org/downloads/
- При установке отметить галочку **"Add Python to PATH"**

### 2. OpenCode
- Скачать для Windows: https://opencode.ai
- Установить как обычное приложение

### 3. VS Code (опционально, для редактирования)
- Скачать: https://code.visualstudio.com/

---

## Регистрация и API ключ

Для работы скриптов нужен ключ Anthropic Claude API:

1. Зарегистрируйтесь на https://console.anthropic.com/
2. Перейдите в раздел **API Keys**
3. Нажмите **Create Key**, скопируйте ключ
4. Первые $5 — бесплатно (достаточно для сотен запросов)

## Установка проекта

```bash
# 1. Клонировать или скачать проект
cd bpmn-generator

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Создать .env файл
copy .env.example .env
# Открыть .env и вставить ваш API ключ:
# ANTHROPIC_API_KEY=sk-ant-...
```

## Запуск через OpenCode

Откройте папку проекта в OpenCode и пишите команды на русском языке:

```
Разбери процесс из файла examples/process_report.txt
```
```
Сгенерируй BPMN диаграмму
```
```
Добавь шаг "Проверить договор" после задачи "Отправить на согласование"
```

OpenCode автоматически вызовет нужные скрипты через скиллы.

---

## Запуск вручную (без OpenCode)

```bash
# Шаг 1: Парсинг текстового файла
python scripts/parse_process.py examples/process_report.txt

# Шаг 2: Генерация BPMN
python scripts/generate_bpmn.py

# Шаг 3 (опционально): Обновление диаграммы
python scripts/update_bpmn.py "добавь шаг X после задачи Y"
```

## Формат входного файла

```
БИЗНЕС-ПРОЦЕСС: Название процесса
============================================================

УЧАСТНИКИ:
  - Имя участника (lane_id)

ЭЛЕМЕНТЫ ПРОЦЕССА:
  [startEvent] Название → Участник
  [task] Название задачи → Участник
  [exclusiveGateway] Вопрос для ветвления? → Участник
  [endEvent] Название → Участник

ПОТОКИ:
  Источник --> Цель
  Источник --> Цель (условие перехода)
```

Типы элементов:
| Тип | Описание |
|-----|----------|
| `startEvent` | Начало процесса (один) |
| `endEvent` | Конец процесса (один или несколько) |
| `task` | Задача, действие |
| `exclusiveGateway` | Ветвление (если/или) |

## Структура проекта

```
bpmn-generator/
├── .opencode/
│   └── skills/
│       ├── parse_process.md    # Скилл: парсинг текста
│       ├── generate_bpmn.md    # Скилл: генерация BPMN
│       └── update_bpmn.md      # Скилл: обновление диаграммы
├── scripts/
│   ├── parse_process.py        # Парсер текста → JSON
│   ├── generate_bpmn.py        # Генератор JSON → BPMN XML
│   └── update_bpmn.py          # Обновление через Claude API
├── templates/
│   └── process.bpmn.j2         # Jinja2 шаблон BPMN
├── examples/
│   └── process_report.txt      # Пример входного файла
├── output/                     # Сюда сохраняются результаты
│   ├── process.json
│   └── process.bpmn
├── requirements.txt
├── .env.example
└── README.md
```

## Возможности

| Действие | Как |
|----------|-----|
| Сгенерировать диаграмму из текста | Команда OpenCode или скрипт |
| Добавить/удалить элемент | Написать OpenCode на русском |
| Переименовать участника или задачу | Написать OpenCode на русском |
| Редактировать визуально | Открыть .bpmn в Camunda Modeler |
| Поделиться диаграммой | Отправить файл output/process.bpmn |
