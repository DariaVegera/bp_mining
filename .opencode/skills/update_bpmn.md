# Скилл: update_bpmn

## Когда использовать
Когда пользователь:
- Хочет изменить существующую диаграмму
- Просит "добавь шаг", "удали элемент", "переименуй задачу"
- Говорит "измени процесс", "скорректируй схему"

## Предусловие
Файл `output/process.json` должен существовать.

## Шаги выполнения

1. Получи от пользователя точное описание изменения.
   Если запрос расплывчатый — уточни что именно нужно изменить.

2. Запусти команду, передав описание изменения в кавычках:
```
python scripts/update_bpmn.py "описание изменения"
```

Примеры:
```
python scripts/update_bpmn.py "добавь шаг 'Проверить документы' после задачи 'Получить заявку'"
python scripts/update_bpmn.py "удали шлюз 'Изделие из прайса?' и соедини напрямую"
python scripts/update_bpmn.py "переименуй участника 'Экономист' в 'Финансовый аналитик'"
python scripts/update_bpmn.py "добавь нового участника 'Юрист' и задачу 'Проверить договор'"
```

3. Скрипт автоматически:
   - Обновит `output/process.json`
   - Перегенерирует `output/process.bpmn`

4. Сообщи пользователю что диаграмма обновлена и напомни как её открыть.

## Советы по формулировке изменений

- Чем точнее описание — тем лучше результат
- Указывай точные названия элементов
- Можно попросить несколько изменений за раз

## Возможные ошибки

- **process.json не найден** — сначала запусти parse_process
- **Нет ANTHROPIC_API_KEY** — нужен .env файл
- **Некорректный JSON от API** — попробуй переформулировать запрос
