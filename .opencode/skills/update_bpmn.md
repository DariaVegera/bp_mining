# Скилл: update_bpmn

## Когда использовать
Когда пользователь хочет изменить диаграмму: добавить/удалить элемент, переименовать, исправить ошибки валидации.

## Референсные файлы (прочитай перед запуском)
- `output/process.json` — текущее состояние процесса
- `examples/bpmn_example.bpmn` — эталон корректной структуры
- `prompts/parse_process.txt` — правила формата JSON

## Шаги выполнения

1. Если запрос расплывчатый — уточни что именно изменить.

2. Запусти:
```
python scripts/update_bpmn.py "точное описание изменения"
```

Примеры:
```
python scripts/update_bpmn.py "добавь шаг 'Проверить договор' после задачи 'Отправить на согласование'"
python scripts/update_bpmn.py "удали шлюз 'Изделие из прайса?' и соедини напрямую"
python scripts/update_bpmn.py "добавь участника 'Юрист' и задачу 'Проверить договор'"
```

3. После обновления **обязательно** запусти валидацию:
```
python scripts/validate_bpmn.py
```

4. Сообщи результат и напомни как открыть диаграмму.

## Ошибки
- process.json не найден — сначала parse_process
- Некорректный JSON от скрипта — переформулируй запрос точнее
