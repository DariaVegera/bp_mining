# Скилл: parse_process

## Когда использовать
Когда пользователь:
- Даёт текстовый файл с описанием бизнес-процесса
- Просит "разобрать процесс", "распарсить файл", "прочитать процесс"
- Упоминает .txt файл с процессом

## Что делает
Запускает скрипт, который читает текстовый файл и извлекает структуру процесса в JSON.

## Шаги выполнения

1. Убедись, что пользователь указал путь к файлу. Если нет — спроси.

2. Запусти команду:
```
python scripts/parse_process.py <путь_к_файлу>
```

Пример:
```
python scripts/parse_process.py examples/process_report.txt
```

3. Скрипт сохранит результат в `output/process.json`

4. Сообщи пользователю:
   - Сколько участников найдено
   - Сколько элементов найдено  
   - Сколько потоков найдено
   - Что следующий шаг — генерация BPMN

## Возможные ошибки

- **Файл не найден** — попроси уточнить путь
- **Нет ANTHROPIC_API_KEY** — попроси создать .env файл по примеру .env.example
- **Ошибка парсинга JSON** — скажи, что текст не удалось разобрать, попроси проверить формат

## Формат входного файла (структурированный)

```
БИЗНЕС-ПРОЦЕСС: Название
УЧАСТНИКИ:
  - Имя участника (lane_id)
ЭЛЕМЕНТЫ ПРОЦЕССА:
  [startEvent] Название → Участник
  [task] Название → Участник
  [exclusiveGateway] Вопрос? → Участник
  [endEvent] Название → Участник
ПОТОКИ:
  Источник --> Цель (условие)
```
