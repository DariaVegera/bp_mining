# Скилл: parse_process

## Когда использовать
Когда пользователь даёт текстовый файл с описанием бизнес-процесса или просит разобрать процесс.

## Референсные файлы (прочитай перед запуском)
- `examples/process_report.txt` — эталонный входной текст
- `output/process.json` — эталонный выходной JSON (после первого запуска)
- `prompts/parse_process.txt` — системный промпт с few-shot примером

## Шаги выполнения

1. Убедись что пользователь указал путь к файлу. Если нет — спроси.

2. Запусти:
```
python scripts/parse_process.py <путь_к_файлу>
```

3. Сообщи пользователю сколько найдено участников, элементов, потоков.

4. Следующий шаг — скилл generate_bpmn.

## Формат входного файла
```
БИЗНЕС-ПРОЦЕСС: Название
УЧАСТНИКИ:
  - Имя участника (lane_id)
ЭЛЕМЕНТЫ ПРОЦЕССА:
  [startEvent] Название → Участник
  [task] Название → Участник
  [exclusiveGateway] Вопрос? → Участник
  [endEvent] Название → Участник
ПОТОКИ:
  Источник --> Цель (условие)
```

## Ошибки
- Файл не найден — уточни путь
- Текст не структурирован — скажи пользователю что нужен структурированный формат
